## Default Permission

Expose offline native RoomPlan capture controls.

#### This default permission set includes the following:

- `allow-cancel-capture`
- `allow-check-permissions`
- `allow-accept-pending`
- `allow-current-capture`
- `allow-import-legacy-reference`
- `allow-reject-pending`
- `allow-is-available`
- `allow-request-permissions`
- `allow-preview-reference`
- `allow-start-capture`
- `allow-stop-capture`
