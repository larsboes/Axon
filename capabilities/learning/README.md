# learning

Generative learning wiki — the first consumer of a local-AI rung (oMLX) in Axon. A capability,
not an app or a lib: it owns a real domain (oMLX inference over source material, its own
schema type once built — nothing under `schemas/` yet — and an upstream verdict pending) even
though its ISA describes a future `dashboard` route — that's `dashboard` consuming this
capability later, same relationship as `transit-server`/`scout-server`/`axon-status`, not a
reason to demote it below capability. See `README.md#three-architectural-nouns` (three nouns, and the
domain-ownership bar that comes with them).

No verdict yet, no container, no code — currently just the ISA below, same "a capability may BE
its README/ISA for now" stage as `capabilities/server` was before anything got built.

See `ISA.md` for the full specification — ported (distilled ISC criteria and constraints only,
not duplicated wholesale) from the LifeOS-mono learning service.
