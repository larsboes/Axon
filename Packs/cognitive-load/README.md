# Cognitive Load Pack

This pack provides tools to shape LLM outputs to match the reader's current cognitive state.

## Included Skills

- **`attention-control`**: High-speed, low-distraction protocol. Uses controlled vocabulary and action-first shaping. Ideal for ADHD-friendly, high-load environments.

## Usage

Use specific skills to adjust the "density" of the conversation. For example, use `/attention-control` when you need to execute tasks without preamble or distraction.
