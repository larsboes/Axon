# Attention Control Doctrine

## The Why: ADHD and Cognitive Load
Aviation uses controlled phraseology because a distracted human under load will mishear instructions. The same applies to reading.

### Five Driving Facts
1.  **Working memory is small.** Anything not on screen is gone.
2.  **Knowing is not doing.** Work dies in the gap between understanding and execution.
3.  **Starting is the hardest step.** The first action must be obvious and small.
4.  **Time is non-linear.** "A bit of work" and "a few hours" register as the same.
5.  **Dopamine is scarce.** Visible progress (the "win") must be obvious.
